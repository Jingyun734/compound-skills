# translator

翻译skill负责将用户的需求用项目语言写成正式的需求文档。

## 输入

- 用户的原始需求（自然语言）
- 项目语言定义：`projects/<项目名>/language.md` 或从 startup.md 中提取
- 比喻skill产出的确认项

## 执行

1. 解析用户的全部需求点
2. 逐条用项目语言翻译
3. 保持翻译的一致性和完整性
4. 对于无法翻译的模糊需求，标注出来
5. 翻译完成后交由评估器检查准确性

## 输出

```markdown
# 需求文档

## 概述
用项目语言描述的总体目标

## 需求条目
1. 项目语言描述的需求项
2. ...

## 模糊项
- 无法翻译的原始需求，需要用户澄清
```

## 质量标准

- 每条需求必须有明确的验收标准
- 不引入用户没有表达的需求
- 项目中所有已有概念必须用既定的语言表述
- 翻译映射规则优先从 `projects/<项目名>/language.md` 获取

## 常见失败

- 过度解读用户需求，添加用户没说的
- 翻译不忠实，漏掉关键约束
- 对不同用户表述相同的概念时翻译不一致
