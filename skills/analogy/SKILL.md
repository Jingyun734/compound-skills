# analogy

比喻skill的职责是桥接抽象项目语言和用户的具体理解。

## 输入

- 设计好的项目语言（术语表、核心概念）
- 用户可能的场景描述

## 执行

1. 分析项目语言中的核心概念
2. 为每个抽象概念构造一个具体比喻
3. 通过比喻向用户描述项目要做什么
4. 将比喻描述反推回用户场景，让用户确认理解是否正确
5. 获取用户在比喻框架下表达的额外需求

## 输出

- 用户对项目的理解确认
- 用户在比喻框架下表达的附加需求
- 如有误解，标记出需要修正的项目语言部分

## 质量标准

- 比喻必须贴近用户的实际场景
- 不问"你确认吗"，而是通过例子让用户自然发现不对
- 项目特定的场景定义：`projects/<项目名>/scenario.md`

## 常见失败

- 比喻和项目实际目标脱节，引导出错误需求
- 比喻引入用户在项目中不需要的联想
