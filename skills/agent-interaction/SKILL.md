# agent-interaction

当规划skill决定分代理时，本skill负责代理间的协调。

## 执行

1. 收到规划skill的task列表
2. 按依赖关系启动各子代理，传入各自的task
3. 监控各子代理的执行状态
4. 子代理完成后，收集产物并传递给依赖该产物的下游代理
5. 汇总所有产物，交还主流程

## 输入

- 规划skill产出的 task 方案
- 项目中已加载的 skill 列表

## 输出

- 各子代理的执行结果集合
- 如有失败或阻塞，附原因

## 监控规则

- 子代理超过预估时间 1.5 倍 → 检查是否需要干预
- 子代理产出不符合验收标准 → 退回重做一次
- 重做仍不通过 → 标记失败，通知用户决策

## 项目定制

- 子代理角色列表：`projects/<项目名>/agent-roles.md`
- 不同角色可用的 skill 从 `knowledge/skills/` 按需加载

## 常见失败

- 子代理间传递的产物丢失或格式不匹配
- 并行子代理产生竞态（对同一文件/数据的同时修改）
- 等待依赖的子代理没有正确阻塞，提前执行
